# Research evidence

This directory preserves scientific methods, reviewed source catalogs and compact
pilot/benchmark reports from development. Historical reports describe their
original datasource and implementation, not necessarily the current serving
stack. See the root README and `db/WORLD_IMPORT.md` for the current global data.

Raw downloads, tile outputs, checkpoints, packed validation matrices, large query
profiles and serving snapshots are generated artifacts excluded from Git. They
remain on the acquisition computer; scripts under `scripts/` and `db/` preserve
the processing paths. Some historical report links require these local outputs.
Do not commit credentials, per-account job receipts or the world import's private
token-path configuration.
